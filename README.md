# DataAnalysisScripts
This is a repository for useful code for data analysis, machine learning, and data visualization. In the past I've inherited many scripts from old analysis efforts, so this is an effort to organize new and old things in one place.

## plot_spectrometer_data.py
Plots reflectance and transmission data from a physics laboratory spectrometer.

## cleanDateframe.py
Cleans NA values from a pandas dataframe and decreases memory usage

## 2D_ColoredHist.py
Generates 2D histograms and uses seaborn to update the color scheme.
